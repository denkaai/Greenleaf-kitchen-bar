## 📁 Project Structure

```
src/
├── assets/images/        # Restaurant imagery
├── components/
│   ├── Navbar.jsx        # Sticky glassmorphism navbar
│   ├── Footer.jsx        # Elegant footer with hours & socials
│   ├── Hero.jsx          # Reusable full-screen hero
│   ├── DishCard.jsx      # Dish card with hover zoom
│   ├── SectionTitle.jsx  # Animated section headings
│   └── Chatbot.jsx       # "Lili 🌿" — AI booking assistant
├── pages/
│   ├── Home.jsx          # Hero, Dishes, Testimonials, Gallery
│   ├── About.jsx         # Story, Mission, Chef, Sustainability
│   ├── Menu.jsx          # 6 categories with filter tabs
│   ├── Events.jsx        # Event hosting + reservation form
│   └── Contact.jsx       # Contact info, map, message form
├── App.jsx               # Router + page transitions
├── main.jsx              # Entry point
└── index.css             # Tailwind directives + global styles
```

## 🤖 Chatbot — Lili 🌿

A floating AI booking assistant visible on every page.

**Features:**

- Step-by-step reservation flow (Name → Date → Time → Guests → Phone)
- Quick-action buttons: Book a Table, View Menu, Opening Hours, Contact, Events
- Typing animation & smooth open/close transitions
- WhatsApp fallback integration
- No backend required — fully client-side

---

## ✨ Animations

Powered by **Framer Motion**:

- 🎬 Smooth fade-in on scroll
- 📤 Slide-up section reveal
- 🔍 Image zoom on hover
- 🔘 Button scale hover effect
- 🧊 Sticky transparent → solid navbar on scroll
- 🔄 Smooth page transitions between routes

## 🚀 Getting Started

```bash
# Clone the repo
git clone https://github.com/denkaai/Greenleaf-kitchen-bar.git

# Install dependencies
npm install

# Start dev server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.
